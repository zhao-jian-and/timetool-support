# 竹林时光 - 隐私政策

最后更新日期：2025年2月5日

## 1. 信息收集

我们非常重视您的隐私。竹林时光可能收集以下信息：

- **事件数据：** 您创建的事件、倒计时、纪念日、心情记录等信息。这些数据仅存储在您的设备本地和您的iCloud账户中。
- **使用数据：** 应用崩溃日志和性能数据，用于改进应用性能和修复bug。
- **订阅信息：** 如果您订阅了高级功能，我们将收集订阅状态和交易信息。

## 2. 数据存储

您的所有个人数据都存储在：

- **本地设备：** 数据加密存储在您的iPhone或iPad上
- **iCloud：** 如果您启用了iCloud备份，数据将加密上传至您的iCloud账户

我们不会将您的个人数据存储在我们的服务器上。

## 3. 数据共享

我们承诺：

- 不会向第三方出售、交易或转让您的个人信息
- 不会与第三方共享您的个人数据
- 仅在以下情况下可能披露您的信息：
  - 获得您的明确同意
  - 法律法规要求
  - 保护我们的权利和财产

## 4. 第三方服务

本应用可能使用以下第三方服务：

- **Apple StoreKit：** 用于处理应用内购买和订阅
- **iCloud：** 用于数据同步和备份
- **Apple通知服务：** 用于发送提醒通知

这些服务仅用于提供应用功能，不会收集您的个人信息用于其他目的。

## 5. 数据安全

我们采取多种安全措施保护您的数据：

- 使用iOS设备加密功能保护数据
- 支持Face ID/Touch ID生物识别锁定
- iCloud数据传输采用端到端加密
- 定期更新应用以修复安全漏洞

## 6. 您的权利

您对自己的数据拥有完全控制权：

- **访问权：** 随时查看您的所有数据
- **删除权：** 可以删除应用中的任何数据
- **导出权：** 可以通过iCloud备份导出您的数据
- **退出权：** 可以卸载应用，删除所有数据

## 7. 儿童隐私

本应用面向所有年龄段用户。我们不会故意收集未满13岁儿童的个人信息。如果我们发现收集了此类信息，将立即删除。

## 8. 政策变更

我们可能会不时更新本隐私政策。重大变更时，我们会通过应用内通知或邮件告知您。继续使用应用即表示您接受更新后的政策。

## 10. Apple隐私标签

本应用的隐私标签详情：

- **收集的数据：** 联系信息、用户内容、使用数据、诊断数据
- **关联到您的数据：** 事件数据、心情记录、订阅信息
- **未关联到您的数据：** 崩溃日志、性能数据
